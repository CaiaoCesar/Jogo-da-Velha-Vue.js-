## ✨ Características

- 🎯 **Interface moderna** com design responsivo
- 👥 **Sistema de placar** em tempo real  
- 🔄 **Alternância automática** de jogadores
- 📱 **Layout responsivo** para mobile e desktop
- 🎨 **Design elegante** com gradientes e animações
- ⚡ **Desenvolvido com Vue.js 3**

## 🚀 Como Jogar

1. **Digite os nomes** dos jogadores
2. **Clique em uma célula** para fazer sua jogada
3. **Forme uma linha** de 3 símbolos iguais (horizontal, vertical ou diagonal)
4. **O primeiro jogador** a formar a linha vence a rodada!
5. **Reinicie o jogo** para começar uma nova partida

## 🛠️ Tecnologias Utilizadas

- **Vue.js 3** - Framework JavaScript progressivo
- **CSS3** - Estilização com gradientes e animações
- **HTML5** - Estrutura semântica
- **JavaScript ES6+** - Lógica do jogo

## 🎯 Regras do Jogo

- O tabuleiro é uma grade 3x3
- Dois jogadores alternam entre X e O
- O objetivo é formar uma linha de 3 símbolos iguais
- As linhas podem ser horizontais, verticais ou diagonais
- Se todas as células forem preenchidas sem um vencedor, é empate!

## 📱 Funcionalidades

### 🏆 Sistema de Placar
- Contagem de vitórias para cada jogador
- Registro de empates
- Nomes personalizáveis dos jogadores

### 🔄 Alternância Inteligente
- O jogador que inicia alterna a cada rodada
- Indicação visual de quem está na vez

### 🎨 Design
- Gradientes modernos em verde
- Animações suaves ao interagir
- Layout adaptável para todos os dispositivos

## 📦 Instalação e Execução

### Pré-requisitos
- Node.js (versão 16 ou superior)
- npm ou yarn

### Passos para executar localmente

```bash
# Clone o repositório
git clone https://github.com/CaiaoCesar/Jogo-da-Velha-Vue.js-.git

# Entre na pasta do projeto
cd Jogo-da-Velha-Vue.js-

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run serve

# Ou construa para produção
npm run build

```
